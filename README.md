# 🎙️ Студія Тюнінгу Вокалу, Звукорежисури та Аранжування

Сучасний інтерактивний веб-сайт портфоліо звукорежисера та аранжувальника з живим A/B плеєром порівняння треків у реальному часі.

---

## 🌟 Ключові можливості сайту

1. **Інтерактивний синхронний A/B плеєр**:
   - Миттєве безшовне перемикання між двома станами треку:
     - **🔴 ДО**: сирий вокал без тюнінгу та обробки (фальшиві ноти, нестійкий пітч, без ефектів).
     - **🟢 ПІСЛЯ**: ювелірний тюнінг у Celemony Melodyne, просторова реверберація, стерео-делей, оптична компресія та шовковистий EQ.
   - Під час перемикання аудіо продовжує грати з тієї самої мілісекунди без перезапуску!
   - Реальний спектральний візуалізатор (Canvas Spectrum & Oscilloscope Wave) з неоновими кольорами.
   - Візуальний монітор активних ефектів (FX Chain Rack).
   - Вбудований синтезатор для демо-прослуховування, якщо файли ще не завантажені.
   - Можливість вибрати власні 2 аудіофайли прямо у браузері або покласти їх у папку `audio/`.

2. **Повний перелік послуг**:
   - 🎯 **Тюнінг вокалу в Celemony Melodyne**: ручне виправлення неточних нот зі збереженням природного дихання та вібрато або стильним Auto-Tune.
   - 🎚️ **Звукорежисура та мастеринг вокалу**: компресія, стерео-делеї, реверберація, деессер та частотне зведення.
   - 🤖 **Аранжування пісень у Suno AI**: генерація, доопрацювання структури, чистка та мастеринг треків.
   - 🎹 **Аранжування під синтезатор Yamaha**: живий акомпанемент, клавішні партії, фортепіано та педи.
   - 🍏 **Аранжування в GarageBand**: продакшн мінусовок, бітів, партій гітар та синтезаторів.

3. **Кольорова гама та дизайн**:
   - Домінуючий блакитний/небесний колір (Sky Blue / Cyan).
   - Акцентні неонові відтінки рожевого (Neon Pink) та теплого заходу сонця (Sunset Orange).
   - Сучасний скляний дизайн (Glassmorphism), підсвічування кнопок та адаптивність для ПК і смартфонів.

4. **Фонові заставки програм та інструментів**:
   - Вбудовані якісні графічні заставки для:
     - **FL Studio 24** (Мікшер, параметричний еквалайзер, канали)
     - **Celemony Melodyne 5** (Нотні краплі, пітч-сітка, вібрато)
     - **Apple GarageBand** (Доріжки, ламповий комбопідсилювач, смарт-контроли)
     - **Синтезатор Yamaha Workstation** (Клавіатура, колеса Pitch/Modulation, кольоровий дисплей)
   - Кнопка **«🖼️ Фонова заставка»** біля кожної програми дозволяє одним кліком встановити її фоном усього сайту!
   - Можливість легко замінити ілюстрації на власні скріншоти у папці `images/`.

---

## 🚀 Як відкрити сайт

Просто двічі клікніть по файлу **`index.html`** у будь-якому браузері (Google Chrome, Microsoft Edge, Safari, Firefox, Opera)!
Сайт повністю автономний, не потребує підключення до інтернету чи встановлення додаткових програм.

---

## 📁 Структура файлів

- **`index.html`** — головна сторінка сайту.
- **`style.css`** — стилі, анімації, блакитна палітра з рожевим та оранжевим акцентами.
- **`app.js`** — движок A/B плеєра, Web Audio API, візуалізатор, перемикач фонів.
- **`images/`** — фонові заставки для FL Studio, Melodyne, GarageBand та Yamaha:
  - `fl_studio.svg`
  - `melodyne.svg`
  - `garageband.svg`
  - `yamaha.svg`
  - `ЯК_ЗМІНИТИ_КАРТИНКИ.txt` — інструкція щодо додавання власних скріншотів.
- **`audio/`** — папка для ваших аудіотреків:
  - `track_before.wav` (або `track_before.mp3`) — трек ДО обробки і тюнінгу.
  - `track_after.wav` (або `track_after.mp3`) — трек ПІСЛЯ обробки і тюнінгу.
  - `ЯК_ДОДАТИ_СВОЇ_ТРЕКИ.txt` — коротка пам'ятка.
